# Pizza Premium PWA

Create a complete production-ready, mobile-first food delivery app inspired by premium pizza delivery brands, using Lovable Cloud for authentication, database, storage, and real-time updates. Build a premium dark Material 3-inspired design with black/charcoal surfaces, warm orange accents, polished food imagery, and smooth interactions. Include customer authentication; restaurant listings; food categories; search; menu/item pages; favorites; cart; checkout; live order tracking; profile; and order history. Also build a protected admin dashboard to manage restaurants, menu items, orders, customers, promotions, and offers. Seed realistic demo data and make all primary flows functional. Design it as an Android-ready PWA/mobile experience suitable to later package for Play Store deployment.

This project was built with [Lovable](https://lovable.dev).
